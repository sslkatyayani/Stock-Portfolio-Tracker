# Stock-Portfolio-Tracker
A Python script to track the current market value of your stock portfolio using real-time data from Yahoo Finance.

## Features

- Uses yfinance to fetch live stock prices.
- Calculates the total value of your portfolio.
- Prints individual stock details and total valuation.
- Customizable stock list and share quantity.

## Requirements

- Python 3.11
- yfinance library
